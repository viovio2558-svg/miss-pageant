# เว็บรับสมัครประกวดระดับประเทศ (เวทีเจ้าภาพในเครือ Miss Moohong) — คู่มือติดตั้ง

ระบบเดียวกับ Miss Moohong แต่:
- พื้นที่ = รัฐ/จังหวัดของประเทศเจ้าภาพ (ตัวอย่างในระบบคือ 28 รัฐ + 8 เขตสหภาพของอินเดีย แก้ได้ในหน้าแอดมิน)
- 1 คนสมัครได้ 1 พื้นที่ / 1 Username สมัครได้ 1 ครั้ง ไม่มีการแบ่งทวีป
- ไม่มีทำเนียบผู้ชนะ ไม่มีสรุปการแข่งขัน ไม่มี "ครั้งที่"
- มี co-admin แบบกำหนดสิทธิ์รายคน (แอดมินหลักเพิ่มที่หน้าแอดมิน → "ผู้ช่วยแอดมิน") co-admin เข้าหน้าแอดมินโดยกรอกชื่อและรหัสของตัวเองที่หน้าเข้าสู่ระบบ ไม่ติ๊กสิทธิ์ = เข้าไม่ได้ ตารางจะเพิ่มคอลัมน์ให้อัตโนมัติ ไม่ต้องรันคำสั่งเพิ่ม
- ชื่อเวทีแก้ได้ที่หน้าแอดมิน → "ตั้งค่าการรับสมัคร" → ชื่อเวที เช่น `Miss Host` แสดงตามที่พิมพ์ ไม่มีดาว
- สีเว็บ (พื้นหลัง สีหลัก สีรอง) แก้ได้ที่ "ตั้งค่าการรับสมัคร" มีปุ่มคืนสีเดิม

## ขั้นตอน (ต้องทำเป็นโปรเจกต์ใหม่ แยกจากเว็บ Miss Moohong)
1. สร้าง GitHub repo ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ต้องมีโฟลเดอร์ `src/` และ `public/` ตามเดิม)
2. Cloudflare → Storage & Databases → D1 → Create database ชื่อ `miss-pageant-db`
3. เข้า D1 ตัวนั้น → Console → วางคำสั่งใน `schema.sql` ทีละคำสั่ง (ไม่ใส่บรรทัดคอมเมนต์ `--`) แล้ว Execute
4. เปิดไฟล์ `wrangler.jsonc` บน GitHub แก้ `database_id` เป็น ID ของ D1 ที่สร้าง
5. Workers & Pages → Create → Import a repository → เลือก repo นี้ (Build command เว้นว่าง, Deploy command `npx wrangler deploy`)
6. Worker → Settings → Variables and secrets → เพิ่มแบบ **Secret** (ส่วน Runtime ไม่ใช่ Build): `ADMIN_PASSWORD` และ `SESSION_SECRET` (สุ่มยาว ๆ) แล้ว Deploy ใหม่
7. เปิด Settings → Domains & Routes → เปิด workers.dev
8. เข้า `/#admin` ใส่รหัส → ตั้งชื่อเวที, เวลาเปิด-ปิด, รายชื่อพื้นที่, รูปสไลด์หน้าแรก

## เปลี่ยนปี / เปลี่ยนเจ้าภาพ
- แก้ "ชื่อเวที" และ "รายชื่อพื้นที่" ในหน้าแอดมินได้ทันที ไม่ต้องแก้โค้ด
- ผู้สมัครปีเก่าจะยังอยู่ในฐานข้อมูล ถ้าเริ่มปีใหม่ แนะนำสร้าง D1 ฐานใหม่ หรือลบแถวใน D1 Console: `DELETE FROM countries; DELETE FROM slips; DELETE FROM reviews;`

## ข้อควรระวัง
- อย่าลบ/เปลี่ยนชื่อพื้นที่ที่มีคนจองแล้ว (ระบบจะเตือนก่อนบันทึก)
- ชื่อพื้นที่ที่ไม่ใช่ตัวอักษรละติน (เช่น 北海道) ใช้ได้ ระบบสร้างรหัสให้อัตโนมัติ
- ทดสอบกับ D1 จำลองในเครื่องเท่านั้น ยังไม่ได้ลองบน Cloudflare จริง
- ใต้ชื่อเวทีมีข้อความ "Presented by ..." (ขีดเส้นใต้ ลิงก์ไปเว็บผู้จัดหลักได้) แก้ข้อความ/ลิงก์ ฟอนต์ และเปิด-ปิดดาวได้ที่ "ตั้งค่าการรับสมัคร"
- เวอร์ชันนี้ไม่มีการชำระเงิน: สมัครแล้วพื้นที่ล็อกทันที แต่ชื่อจะขึ้นทำเนียบหลังแอดมินกด "ยืนยัน ขึ้นทำเนียบ" ไม่มีจับเวลา 5 นาที ไม่มีสลิป (แอดมินปล่อยพื้นที่ได้) จำกัดไม่เกิน 5 ใบสมัครต่อ 1 เครือข่าย (IP) กันสแปม
- หน้าแรกมีหัวข้อ "รูปแบบการแข่งขัน" (การ์ด) และ "กำหนดการ" (ไทม์ไลน์) แก้ที่แอดมิน ถ้าไม่ใส่อะไรจะไม่แสดง
- "รูปแบบการแข่งขัน" แสดงเป็นไอคอนตามจำนวนคนแต่ละรอบ (มีปุ่ม "ใส่ตัวอย่างตามภาพ") และ "กำหนดการ" ใส่ลิงก์ได้
- "รูปแบบการแข่งขัน" เป็นกรอบสีเข้มแบบตารางรอบ (TOP 20 / TOP 10 / ... / WINNER) แก้หัวกรอบ ชื่อรอบ จำนวนคน ไอคอนพิเศษ ข้อความคั่นได้ในแอดมิน
